Pengumpulan Data Artikel Wikipedia#

Pada praktikum ini dilakukan proses pengumpulan data dari Wikipedia menggunakan teknik web mining. Data yang dikumpulkan berupa 200 artikel dari Wikipedia.

Proses pengumpulan data dilakukan menggunakan Python, requests, dan Trafilatura. Setiap artikel akan diekstraksi menjadi data terstruktur yang terdiri dari judul, URL, teks artikel, dan jumlah kata.

1. Sumber Data#

Sumber data yang digunakan dalam praktikum ini adalah Wikipedia Bahasa Indonesia.

Wikipedia digunakan sebagai sumber data karena artikel dapat diakses secara bebas melalui internet. Data yang dikumpulkan berupa artikel Wikipedia yang diperoleh melalui API Wikipedia.

for i, item in enumerate(daftar_url, start=1):
    judul = item["judul"]
    url = item["url"]

    try:
        response = requests.get(
            url,
            headers=headers,
            timeout=30
        )

        if response.status_code == 200:
            html = response.text

            teks = trafilatura.extract(
                html,
                include_comments=False,
                include_tables=False
            )

            if teks:
                jumlah_kata = len(teks.split())

                hasil_data.append({
                    "id": i,
                    "judul": judul,
                    "url": url,
                    "teks": teks,
                    "jumlah_kata": jumlah_kata
                })

                print(f"{i}/200 berhasil: {judul}")
            else:
                print(f"{i}/200 teks tidak ditemukan: {judul}")

        else:
            print(f"{i}/200 gagal ({response.status_code}): {judul}")

        time.sleep(0.5)

    except Exception as e:
        print(f"{i}/200 error: {e}")
